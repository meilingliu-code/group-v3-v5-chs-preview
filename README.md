# GROUP V3/V5 — CHS content preview

Standalone GitHub Pages review copy of the restored CHS study, exported October 23, 2026.

## Preserved originals

- CHS: https://childrenhelpingscience.com/exp/studies/6286/
- Original template: https://c-steele.github.io/group-lookit/?rev=guided-walkthrough-20261003

Neither original is edited by this repository. The accidental latest CHS interface conversion was undone before export.

## What this copy does

Renders the CHS parent pages, existing Evelyn narration, three-chime sound check, six-step walkthrough, scored illustrated practice, real-parent practice, baby setup, and V3/V5 source movies. Review navigation exposes all pages and all 32 counterbalance sets. Native CHS camera/consent/recording/upload pages are shown as explicit read-only references, with no submission controls or false upload confirmation. The preview opens at Welcome, grown-ups!; technical and consent references are at the end.

## What it does not do

No webcam/microphone access, recording, consent collection, uploads, participant profiles, saved responses, gaze analysis or payment. The only browser storage used by the original instruction helper is the narration on/off preference. No institutional documents, participant data or credentials are included. It is not an experiment runner, not an approved study, and not an end-to-end CHS recording test. Public GitHub Pages cannot make this an access-controlled participant study. noindex and robots.txt only discourage indexing.

## Run locally

Serve this folder with a static HTTP server. Open index.html through that server. No build or dependencies are required. Query ?arm=V5&condition=V5-PS09 can select a review condition.
